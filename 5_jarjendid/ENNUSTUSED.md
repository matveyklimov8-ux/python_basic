# Prognoosid — ülesanded 03 ja 08

Prognoosid on kirja pandud eraldi failis, nagu tagasisides soovitati.

## Ülesanne 03 — järjendi indeksid

Järjend on `[4, 8, 12, 16, 20]`.

1. `arvud[0]` → `4`
2. `arvud[-1]` → `20`
3. `arvud[2] + arvud[3]` → `12 + 16 = 28`
4. `arvud[len(arvud) - 2]` → `16`
5. `arvud[1] * 2` → `8 * 2 = 16`

## Ülesanne 08 — lõikamine

Järjend on `['A', 'B', 'C', 'D', 'E', 'F']`.

1. `tahed[1:4]` → `['B', 'C', 'D']`
2. `tahed[:3]` → `['A', 'B', 'C']`
3. `tahed[3:]` → `['D', 'E', 'F']`
4. `tahed[-3:-1]` → `['D', 'E']`
5. `tahed[::-1]` → `['F', 'E', 'D', 'C', 'B', 'A']`
