# 5. Järjendid — решения

Эта папка содержит 37 решений `ylesanne01.py`–`ylesanne37.py`, обязательную контрольную `opilaste_tulemuste_analuusaator.py` и восемь учебных файлов данных.

## Запуск

Из корня проекта `python_basic` запусти, например:

```bash
python3 5_jarjendid/ylesanne01.py
python3 5_jarjendid/opilaste_tulemuste_analuusaator.py
```

Файлы, которые читают `.txt` или `.csv`, открывают данные из той же папки, где расположен скрипт. Поэтому их можно запускать и кнопкой **Run Python File** в VS Code.

## Контрольная работа

Основной файл: `opilaste_tulemuste_analuusaator.py`. Исходные данные для него: `kontrolltoo.csv`. Если вводишь `Kati` в строке поиска, ответ должен содержать 94 балла и оценку 5. Для исходного файла статистика должна показывать 10 учеников, среднее 74.1, 8 сдавших и 2 не сдавших.

Подробный разбор находится в файле проекта `РАЗБОР_ВСЕХ_ЗАДАНИЙ.md`, в разделе **5. Järjendid**.
