# Что исправлено по замечаниям преподавателя

В этом комплекте есть две части:

1. `python_basic/` — исправления в темах 1–7 именно по списку замечаний преподавателя.
2. `8_testimine/` — дополнительная тема 8 с обязательным заданием 45 про автоматическое тестирование корзины покупок.

После распаковки открой эту папку в VS Code. Чтобы проверить синтаксис всех файлов Python из основной части, выполни из папки `python_basic`:

```bash
python3 -m compileall -q sissejuhatus 2_tingimuslaused 3_tsuklid 4_soned 5_jarjendid 6_funktsioonid 7_andmevahetus
```

Для темы 8 установи pytest при необходимости:

```bash
python3 -m pip install pytest
```

Перейди в папку `8_testimine` и выполни:

```bash
python3 -m pytest -q test_ostukorv.py
```

Примечание: задания с Tkinter нужно проверять в графической среде; сетевые упражнения требуют интернета. В папке с исправлениями есть `TAGASISIDE_PARANDUSED.md`, где перечислено соответствие каждого комментария преподавателя изменённым файлам. Для циклов 36–38 точное исходное условие с первоначальной ошибкой отсутствовало в доступном экспорте Moodle, поэтому добавлены только подтверждаемые комментарии о корректных границах цикла и изменении счётчика.
