# Что важно понимать

`input()` получает ввод как текст. Для чисел его обычно преобразуют с `int()` (целые числа) или `float()` (числа с дробной частью).

`=` присваивает значение, например `age = 17`. `==` сравнивает значения, например `age == 18`.

В условиях `if` / `elif` / `else` Python выбирает ветвь. `and` требует истинности всех условий, `or` — хотя бы одного, `not` меняет True на False и наоборот.

`%` возвращает остаток от деления: `8 % 2 == 0` означает, что число чётное. `//` возвращает целую часть деления: `137 // 60 == 2`.

`while` повторяет тело, пока условие истинно. Важно менять переменную цикла внутри цикла, иначе программа может повторяться бесконечно.

В строках полезны `len()`, индексы (`text[0]`), срезы (`text[::-1]`), методы `strip()`, `lower()`, `upper()`, `replace()`, `find()` и `split()`.

В графических заданиях используется `tkinter.Canvas`: координаты задаются от левого верхнего угла окна; `create_rectangle`, `create_oval`, `create_line`, `create_polygon` и `create_text` рисуют элементы.

## Järjendid ehk списки

Список хранит несколько значений в определённом порядке: `linnad = ["Tartu", "Tallinn"]`. Индексы начинаются с нуля: `linnad[0]` — первый элемент, `linnad[-1]` — последний. Длина списка получается через `len(linnad)`.

`append(x)` добавляет элемент, `x in loend` проверяет, содержится ли значение, `count(x)` считает повторы. Срез `arvud[1:4]` берёт элементы с индекса 1 по индекс 3: правая граница не включается. `arvud[::-1]` создаёт элементы в обратном порядке.

`for element in loend` проходит по значениям списка. `for i in range(len(loend))` проходит по индексам, что удобно для изменения элементов на месте: `loend[i] = loend[i] * 1.10`. Простое присваивание переменной цикла не меняет сам список.

Чтобы анализировать данные, удобно вести счётчик и накопитель суммы. Сумма начинается с `0`; каждый новый подходящий элемент прибавляется оператором `summa += arv`. Для файлов используй `with open(tee, encoding="utf-8") as fail:`. `Path(__file__).with_name("arvud.txt")` находит файл рядом с программой, а `strip()` убирает перенос строки с краёв.

В CSV-упражнениях `rida.split(";")` разделяет запись на поля, например `"Mari;87"` на имя и баллы. Баллы нужно преобразовать в число через `int()`. В обязательной контрольной имена и баллы лежат в параллельных списках с одинаковыми индексами: `nimed[i]` соответствует `punktid[i]`.
