# 6. Funktsioonid — selgitused vene keeles

Функция — именованный блок кода, который можно запускать повторно. `def` создаёт функцию, а `имя()` вызывает её. Параметры принимают данные, `return` возвращает значение вызывающему коду, а `print()` только показывает его.

## Контрольная работа: Õpilaste hinnete haldussüsteem

Файл `opilaste_hinnete_haldussusteem.py` — программа с меню. Список `nimed` хранит имена, а `punktid` — баллы: элемент с индексом `i` в обоих списках относится к одному ученику. `lisa_opilane()` проверяет имя и баллы, `arvuta_hinne()` возвращает оценку, функции статистики ищут среднее, лучшего и слабейшего ученика. `otsi_opilane()` сравнивает имена через `casefold()`, поэтому регистр не важен. Цикл меню завершается только при вводе `0`; неправильный пункт и неверные баллы не должны аварийно завершать программу.
