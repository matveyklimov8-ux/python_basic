## Три главные контрольные работы

## Общие правила для объяснения кода

## Самые важные идеи этой темы

### Индексы и срезы

Список `varvid = ["punane", "sinine", "roheline"]` имеет индексы `0`, `1`, `2`. Индекс `-1` выбирает последний элемент. В срезе `arvud[2:5]` включается индекс 2, но не включается индекс 5. Поэтому, чтобы захватить индексы 2–5 включительно, пишут `arvud[2:6]`.

### Изменение списка

`hinnad[0] = 14` меняет первый элемент. Но если внутри цикла написать только `hind = hind * 1.10`, сам список не изменится: переменная `hind` — лишь временное значение. Для изменения элемента нужно писать `hinnad[indeks] = hinnad[indeks] * 1.10`.

### Счётчики и сумма

Счётчик обычно начинается с нуля и увеличивается на 1: `arv += 1`. Накопитель суммы тоже начинается с нуля, но каждый раз получает очередное значение: `summa += arv`. Эти переменные обновляются внутри цикла.

### Чтение файлов

`Path(__file__).with_name("arvud.txt")` строит путь к файлу рядом с самим `.py`, поэтому программа не зависит от текущей папки терминала. `with open(tee, encoding="utf-8") as fail:` открывает текст в UTF-8 и автоматически закрывает его после блока. `rida.strip()` удаляет пробелы и символы переноса строки по краям.

### CSV и параллельные списки

Строка `Mari;87` разбивается на имя и баллы через `split(";")`. Имя добавляется в `nimed`, баллы сначала преобразуются в число через `int()`, затем добавляются в `punktid`. Элементы с одинаковым индексом относятся к одному ученику: `nimed[i]` и `punktid[i]`.

### Обязательная контрольная

В контрольной средний балл — `sum(punktid) / len(punktid)`. Самый высокий балл получается через `max(punktid)`, низший — через `min(punktid)`. Чтобы вывести всех учеников с одинаковым лучшим результатом, нужно проверить каждого: `punktid[i] == korgeim`. Оценка определяется последовательностью `if/elif/else` сверху вниз. `casefold()` позволяет искать имя без различия заглавных и строчных букв.

В исходном примере контрольной должно получиться: 10 учеников, средний балл 74.1, лучший результат Laura — 100, низший Karl — 39, сдали 8 и не сдали 2.

Список `nimed` хранит имена, а `punktid` — баллы: элемент с индексом `i` в обоих списках относится к одному ученику. `lisa_opilane()` проверяет имя и баллы, `arvuta_hinne()` возвращает оценку, функции статистики ищут среднее, лучшего и слабейшего ученика. `otsi_opilane()` сравнивает имена через `casefold()`, поэтому регистр не важен. Цикл меню завершается только при вводе `0`; неправильный пункт и неверные баллы не должны аварийно завершать программу.
